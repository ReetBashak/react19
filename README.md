🌍 Atlas: The React Country Explorer

🌟 Project Overview
Atlas is a dynamic single-page application (SPA) built with React 19 that serves as a comprehensive country detail site. It allows users to quickly look up key information about almost every country in the world, providing a clear and accessible data visualization experience.

This project was developed as a demonstration of modern React practices (including new React 19 features where applicable) and efficient API data handling.

✨ Key Features
Comprehensive Data: Displays vital statistics for each country, including:

Population

Region / Sub-Region

Capital City

Official Languages

Currency(s)

API Powered: Fetches real-time country data from a reliable public REST API.

Curated Data Insights: Utilizes data figures and structural guidance sourced from ChatGPT to enrich and validate the information presented.

Modern UI/UX: Built with a responsive design for seamless viewing on desktop, tablet, and mobile devices.

React 19 Foundation: Developed leveraging the latest features and performance enhancements from the React ecosystem.

💻 Technologies Used
This project is built using the following core technologies:

Category	Technology	Purpose
Frontend	React 19 (JavaScript/JSX)	Core library for building the user interface.
Styling	CSS / SCSS	Custom styling for a clean, modern look.
Data Fetching	Fetch API / Axios	Used to request country data from the external API.
External API	The REST Countries API	Primary source for all country data.
Development	ChatGPT	Used for data validation, code snippets, and structural advice.
⚙️ Local Development Setup
Follow these steps to get a copy of the project running on your local machine.

Prerequisites
Node.js (v18+) and npm or yarn installed.

Git installed.

Installation Steps
Clone the Repository:

Bash

git clone <YOUR_GITHUB_REPO_URL>
cd atlas
Install Dependencies:

Bash

npm install
Run the Project:

Bash

npm run dev 
The application will typically open in your browser at http://localhost:5173 (or similar, depending on your setup).
